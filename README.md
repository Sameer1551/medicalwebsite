# Medical Website

A modern, responsive medical web application built with React, Vite, TypeScript, and Tailwind CSS.

Repository: https://github.com/Sameer1551/medicalwebsite

## Tech Stack
- React 18 + React Router
- TypeScript
- Vite
- Tailwind CSS
- ESLint

## Getting Started

Prerequisites: Node.js 18+ and npm 9+

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

## Project Structure
```
.
├─ src/
│  ├─ components/
│  │  ├─ layout/        # Layout, Navbar, Sidebar, MobileNav
│  │  └─ ui/            # Reusable UI components (Button, Card, etc.)
│  ├─ contexts/         # Global contexts (e.g., LanguageContext)
│  ├─ pages/            # Route pages (Home, SymptomChecker, etc.)
│  ├─ App.tsx           # App routing
│  └─ main.tsx          # App entry
├─ index.html           # HTML template
├─ tailwind.config.js   # Tailwind config
├─ postcss.config.js    # PostCSS config
├─ vite.config.ts       # Vite config
└─ package.json
```
